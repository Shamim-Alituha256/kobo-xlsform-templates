# kobo-xlsform-templates
XLSForm templates for KoboToolBox - ready to upload and deploy for data collection in Uganda.

## Files

| File | Use |
| --- | --- |
| malaria indicator surveys.xlsx | Household malaria survey - household roster, bed net use, fever / treatment, with skip logic and validation |
| NIRA Registration sample.xlsx | NIRA-style registration - personal details, NIN validation, district / parishm consent and photo capture |

## How to use

1. Download the .xlsx file
2. In koboToolbox, go to New project > Upload XLSXForm
3. Upload the file and deploy
4. Collect data with KoboCollect app (works offline)
